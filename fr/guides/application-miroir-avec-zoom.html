Une application miroir avec zoom pour les sourcils, les dents, les lentilles et les petits détails

Un miroir normal vous montre en taille réelle : parfait pour les cheveux, inutile pour tout ce qui est petit. Les miroirs de maquillage règlent ça avec un grossissement 5× ou 10×. Votre iPhone peut faire pareil, sans transporter un objet de plus.

Ce qu’est vraiment le zoom d’un miroir de téléphone

La caméra frontale a une seule focale fixe, donc le zoom d’une application miroir est numérique : l’application recadre le centre de l’image et l’agrandit. C’est exactement ce qu’il faut pour un miroir — vous n’imprimez rien, vous regardez — mais il y a deux limites pratiques :

  • La lumière : plus vous zoomez, plus le grain apparaît. Une bonne lumière frontale (ou un anneau lumineux) compte davantage à 3× qu’à 1×.
  • La stabilité : à fort zoom, chaque tremblement est amplifié. Posez le coude quelque part, ou calez le téléphone.

En pratique, 1,5 à 2,5× couvre presque tout : sourcils, cils, une lentille qu’on pose, un bouton, l’espace entre les incisives après une salade.

Quand le grossissement vaut le coup

  • L’épilation — on distingue chaque poil sur la peau.
  • Les lentilles de contact — vérifier qu’elle est bien en place et pas à l’envers.
  • Les dents — graines de pavot et épinards se cachent à 1×.
  • Le maquillage des yeux — symétrie de l’eye-liner, paquets de mascara.
  • La peau — en sachant qu’à 3×, tous les pores semblent dramatiques. Pas de panique.

Comment faire dans Mirrorly

Mirrorly a un curseur de zoom à l’écran et le zoom par pincement. Pour l’utiliser :

  1. Ouvrez Mirrorly et trouvez ce que vous voulez regarder dans le miroir plein écran.
  2. Glissez le curseur vertical, ou pincez l’écran, pour zoomer. Le grossissement actuel (par exemple 1,7×) s’affiche en bas.
  3. Si l’image est granuleuse, touchez l’ampoule — l’anneau lumineux la nettoie.
  4. Gaucher ? Dans les réglages, vous pouvez déplacer la commande du zoom de l’autre côté, ou la masquer et simplement pincer.
